CAN bus security02/2026 – 04/2026
CAN Bus Encryption Using ChaCha20
  • Designed a hardware-accelerated ChaCha20 stream cipher in Verilog (parallel ARX quarter-round core with FSM) as a “cryptographic firewall” between the host MCU and CAN transceiver, verified in Xilinx Vivado with a CAN 2.0B testbench.
  • Generated a 512-bit keystream block in 235 ns at 100 MHz, about 8.5x faster than a single CAN bit time (2,000 ns at 500 kbps). One block covers up to eight 8-byte CAN frames.
  • Added MAC authentication and a 32-bit rolling-counter nonce so forged and replayed frames fail verification in simulation.
  • Defined a 4-level (A–D) safety classification that encrypts only safety-critical signals, keeping bus load under the 70% threshold.

Hardware root of trust08/2025 – 12/2025
SRAM PUF File Authentication System
  • Built a hardware root of trust on an Arduino Uno (ATmega328P) that derives a 256-bit key from SRAM power-up state, with nothing stored in non-volatile memory. It authenticates sudo through Linux PAM (pam_exec, Python, UART).
  • Developed a 4-step calibration (20 power cycles, stability filtering, spatial distribution, 128/128 bit balancing), reaching 0.9158 bits Shannon entropy.
  • Implemented a Reed-Solomon fuzzy extractor (24 parity symbols, corrects up to 12 bytes) against a measured 5.48% bit-error rate.
  • Achieved 46.06% inter-device vs 5.48% intra-device Hamming distance, giving zero false accepts across 10 tested boards.
